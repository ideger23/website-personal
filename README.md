# Portofolio Online — Ferdi Handoko

Website portofolio responsif untuk desktop dan mobile, siap dipublikasikan dengan GitHub Pages.

## Struktur
- `index.html` — halaman utama
- `style.css` — desain dan responsive layout
- `script.js` — menu mobile + tombol WhatsApp
- `assets/profile.jpg` — foto profil
- `cv-ferdi-handoko.pdf` — tambahkan CV PDF kamu dengan nama file ini

## Sebelum upload
1. Buka `script.js`.
2. Ganti `62XXXXXXXXXX` dengan nomor WhatsApp kamu.
3. Jika ingin, ganti `emailkamu@example.com` pada `index.html`.
4. Masukkan CV PDF dengan nama `cv-ferdi-handoko.pdf` di folder utama.

## Upload ke GitHub Pages
1. Buat repository baru di GitHub, misalnya `portfolio-ferdi`.
2. Upload seluruh isi folder ini.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`.
6. Klik **Save**.
7. Tunggu proses deployment. GitHub akan memberikan alamat website Pages kamu.

Catatan: website ini tidak membutuhkan database atau server; cukup file statis HTML/CSS/JavaScript.
