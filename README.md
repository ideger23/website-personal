# Portfolio Ferdi Handoko

Website portfolio statis untuk GitHub Pages.

## Struktur
- `index.html` — halaman utama
- `style.css` — tampilan responsif
- `script.js` — WhatsApp, tahun otomatis, dan menu mobile
- `CV-Ferdi-Handoko.html` — CV yang dapat dibuka/cetak ke PDF
- `assets/profile.jpg` — foto profil
- `assets/organisasi.jpg` — dokumentasi organisasi

## Deploy ke GitHub Pages
1. Upload seluruh isi folder ini ke repository.
2. Buka **Settings → Pages**.
3. Pilih **Deploy from a branch**.
4. Pilih branch `main` dan folder `/ (root)`.
5. Simpan dan tunggu proses deployment.

Catatan: path gambar sudah dibuat relatif (`./assets/...`) agar aman untuk GitHub Pages.
